# 研究室・走廊・电梯 USD 场景构建规划

> 目标：构建与现实足够接近的 USD 场景，用于 Isaac Sim 机器人导航与仿真。

---

## 一、需要考虑的因素

### 1. 几何结构（Geometry）

最基础的部分，决定场景的物理骨架。

| 要素 | 关注点 |
|------|--------|
| 地板/墙壁/天花板 | 尺寸精度（误差建议 ±2cm 以内） |
| 门 | 宽度、开合方向、是否自动门、轴心位置 |
| 走廊 | 净宽（影响机器人能否通过）、转角半径 |
| 电梯 | 轿厢内净尺寸、门宽、层高、停靠层数 |
| 障碍物 | 固定家具（桌椅、柜子）的位置与外形 |

**关键原则**：机器人导航关心的不是外观细节，而是**可通行空间的形状**。几何精度直接影响导航规划结果。

---

### 2. 物理属性（Physics Schema）

让仿真中的机器人与场景正确交互。

| 要素 | 参数 |
|------|------|
| 地板摩擦系数 | 影响轮式机器人打滑程度（瓷砖 ≠ 地毯） |
| 碰撞体（Collider） | 每个物体需要简化碰撞网格，不能直接用渲染网格 |
| 门的铰链关节 | 转轴位置、开合角度限制、是否有弹簧回复 |
| 电梯运动 | 垂直位移、加速度、开关门时序 |
| 地面平整度 | 是否有坡道、门槛高度（影响轮子跨越） |

---

### 3. 传感器感知环境（Sensor-ready）

机器人用传感器感知世界，场景的外观需要对传感器"真实"。

| 传感器 | 对应的场景要求 |
|--------|--------------|
| LiDAR | 墙/门/柱子的几何精度；玻璃需要特殊处理 |
| RGB 相机 | 纹理贴图（地板花纹、墙色、标识牌）、光照 |
| 深度相机 | 材质反射率（镜面反射会导致深度丢失） |
| IMU | 地面坡度、振动（一般在 Isaac Sim 层处理） |

---

### 4. 语义标注（Semantic）

用于 AI 感知训练（分割、检测）。

- 每类物体设置语义标签（`door`、`wall`、`elevator`、`person`）
- 电梯按钮、门把手等细节是否需要单独标注取决于任务

---

### 5. USD 分层结构设计

好的分层让场景易于维护和扩展。

```
building.usd
├── structure.usd       ← 墙/地板/天花板（静态，极少改动）
├── furniture.usd       ← 桌椅柜子（静态障碍物）
├── doors.usd           ← 所有门（含 Variant：open/closed）
├── elevator.usd        ← 电梯（含动画与物理）
├── lighting.usd        ← 灯光布置
├── materials.usd       ← 材质库
├── physics.usd         ← 物理属性覆盖层
└── semantic.usd        ← 语义标注覆盖层
```

建议把**门的开关状态**和**电梯当前楼层**设计为 `VariantSet`，便于快速切换场景配置。

### 2.2 照片与纹理参考（推荐）

| 拍摄对象 | 用途 |
|---------|------|
| 地板近照（正上方） | 生成地板 PBR 贴图 |
| 墙面近照 | 墙面材质 |
| 走廊全景（鱼眼或广角） | 验证几何比例 |
| 电梯内部（4 个角） | 轿厢材质与尺寸确认 |
| 门把手/电梯按钮近照 | 细节语义标注参考 |

### 2.3 平面图（有则用，没有则自测）

- CAD 文件（.dwg / .dxf）优先
- 建筑管理处申请或查楼层消防疏散图（通常挂在走廊）
- 无以上资源时：激光测距仪 + 手绘草图 → 建模

### 2.4 物理参数参考值

| 材质 | 静摩擦系数 μs | 动摩擦系数 μk |
|------|------------|------------|
| 瓷砖地面（干燥） | 0.5 | 0.4 |
| 瓷砖地面（湿滑） | 0.2 | 0.15 |
| 地毯 | 0.6 | 0.5 |
| 混凝土 | 0.6 | 0.5 |

## 三、需要做的测试

### 3.1 几何验证

- [ ] 用 usdview 打开场景，目视检查比例是否与现实吻合
- [ ] 机器人放入场景后站在地板上（不穿模、不悬空）
- [ ] 走廊净宽足够机器人通过（建议留 ≥ 0.5m 余量）

### 3.2 物理仿真测试

- [ ] 机器人在地板行走不打滑、不抖动
- [ ] 门可以被机器人推开或由程序控制开合
- [ ] 电梯门开关时序正确，轿厢上下移动无穿模
- [ ] 机器人进出电梯时不与门框/地坎碰撞

### 3.3 导航测试

- [ ] 生成 NavMesh，确认走廊、研究室、电梯内部均可导航
- [ ] 机器人从研究室 → 走廊 → 电梯完整路径规划成功
- [ ] 门关闭时导航正确标记为不可通行

### 3.4 传感器测试

- [ ] LiDAR 点云在走廊中形状正确（墙面平行、门洞清晰）
- [ ] 相机画面与现实照片比对（颜色、光照大致吻合）
- [ ] 玻璃/镜面区域 LiDAR 是否需要特殊材质设置

### 3.5 性能测试

- [ ] 完整场景加载时间 < 10s（否则考虑 Payload 拆分）
- [ ] 仿真帧率在机器人运动时稳定（目标 ≥ 60Hz physics step）

## 四、构建顺序建议

```
1. 收集数据（测量 + 拍照 + 平面图）
       ↓
2. 建模结构层（structure.usd）— 地板/墙/天花板
       ↓
3. 添加物理属性（physics.usd）— 先跑通机器人站立
       ↓
4. 添加门与电梯（doors.usd + elevator.usd）— 含动画与关节
       ↓
5. 添加家具障碍物（furniture.usd）
       ↓
6. 添加材质与灯光（materials.usd + lighting.usd）
       ↓
7. 添加语义标注（semantic.usd）
       ↓
8. 全流程测试（3.1 → 3.5）
```

每步完成后单独保存并测试，不要等到全部完成再测。
